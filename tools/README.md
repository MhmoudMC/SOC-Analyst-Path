# Project Tools

This folder is a good place to document reusable Python security scripts and utilities developed during the learning journey.

## Current focus

The repository already contains practical security-learning work in the `Python-for-Security/` folder, including:

- log parsing
- regex-based extraction
- basic threat detection logic
- authentication and anomaly analysis examples

## Suggested structure

```text
tools/
  README.md
  log_ip_extractor.py
  failed_login_monitor.py
  intruder_finder.py
```

## Usage

Run each script locally with Python and feed it a sample log or dataset.

```bash
python3 tools/log_ip_extractor.py sample.log
```

## Note

The purpose here is learning and portfolio demonstration. The focus is clarity, readability, and documented examples rather than production deployment.
