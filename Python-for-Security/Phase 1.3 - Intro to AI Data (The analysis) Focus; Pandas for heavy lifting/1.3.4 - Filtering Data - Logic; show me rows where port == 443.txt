What You Gain 
*	Precision filtering: Log files can have millions of rows. Filtering let's you instantly hide normal traffic and isolate potential security threats.
*	High Speed: Pandas handles calculations across full columns at once, making it vastly faster than using stand Python 'for' loops or 'if' statements over raw text.
*	Multi-Condition Logic: You learn to stack multiple rules together -- such as matching a specific port AND a blocked status-using the '&' operator and parenthess'()'.

# How to use it : Whenever you  want to filter a DataFrame 'df'. you use this standard pattern:
Python [ 

filtered_df = df[ (condition_1) & (condition_2) ] #  General Syntax 

blockd_https = df[ (df['Port'] == 443) & (df['Status'] == 'Block') ] # Security Example (Port 443 AND Blocked Status)
]
