Measures of Spread quantify how much your log data deviates from that average center :

* Range : The gap between the maximum and minimum values.

* Variance: The average squared distance of each log entry from the mean.

* Standard Deviation (np.std()): The square root of variance, measuring how far values typically drift from the normal average (in original units, like logs/hour).

Real world use : Python [
import numpy as np

# 24 hours of log counts
