# SOC Analyst Path

A hands-on blue team learning portfolio focused on SOC operations, detection engineering, Python-based security automation, and incident response. This repository documents my structured learning journey and practical exercises while building foundational cybersecurity skills.

## Why this repository exists

This repo is a personal learning and portfolio workspace, not a production security product. It captures hands-on work across:

- SIEM and detection engineering
- Security log analysis and triage
- Python automation for SOC workflows
- Incident investigation and reporting
- Blue team learning and skill development

## Repository map

- `README.md` — project overview and entry point
- `RESUME_2025.md` — resume-style profile and experience summary
- `Python-for-Security/` — Python fundamentals, SOC automation, and security tooling exercises
- `Phase 1. actual Tools using/` — Splunk/SIEM learning, queries, and detection work
- `Logs & Investigations projects/` — investigation writeups, reports, and exercises
- `Dashboards/` — dashboard-related artifacts and visual outputs
- `SOC Folder- Basics and thinking/` — foundational concepts and analytical notes
- `images/` — screenshots, diagrams, and supporting visuals
- `Resume/` — resume or portfolio materials
- `docs/` — project documentation and learning guidance

## Learning path overview

This repo follows a self-directed SOC analyst progression:

### Phase 0: Fundamentals
- Networking and system basics
- Log analysis fundamentals
- Threat detection and incident response concepts

### Phase 1: SIEM and detection engineering
- Splunk / SIEM querying and investigation workflows
- Detection rule development
- Alert handling and tuning
- Incident response practice and reporting

### Python for Security
- Python fundamentals for security work
- Log parsing and text processing
- Regex and automation for SOC tasks
- Data analysis and simple statistical detection

## Featured work

### Security tooling
Python scripts and exercises focused on extracting, validating, and analyzing security-relevant data from logs and threat sources.

### Detection engineering
Hands-on Splunk SPL work covering:
- brute-force activity
- suspicious login patterns
- privilege escalation indicators
- lateral movement detection
- exfiltration-related alerts

### Incident investigations
Case-based investigations and simulated breach walkthroughs covering attack chain analysis, IOC extraction, timeline reconstruction, and containment recommendations.
