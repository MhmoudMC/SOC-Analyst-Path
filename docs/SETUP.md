# Setup Guide

This repository is primarily a learning and documentation project. Most materials are plain text, notes, scripts, and investigation artifacts rather than a single application with a formal runtime.

## Prerequisites

For the Python-based exercises, you will typically need:

- Python 3.9+
- A terminal or shell
- Optional: pip package installation for data-analysis tasks

## Recommended environment

```bash
python3 --version
pip --version
```

## Install dependencies

If you are working on the Python analysis or data-focused exercises, install the project dependencies:

```bash
pip install -r requirements.txt
```

## Optional libraries

Some learning tasks may involve statistical or data-analysis work using:

```bash
pip install numpy pandas
```

## Repository usage

Explore the folders in this order:

1. `docs/`
2. `Python-for-Security/`
3. `Phase 1. actual Tools using/`
4. `Logs & Investigations projects/`
5. `RESUME_2025.md`

## Notes

- This repo does not require a web server or database to browse the learning materials.
- Many scripts are designed to be run locally against sample logs or exercise files.
- Use the project files as documentation and learning examples rather than production-grade tooling.
