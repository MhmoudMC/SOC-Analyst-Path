# Learning Path

This repository documents a self-directed learning journey into SOC operations, blue team practices, and security engineering foundations.

It is intentionally focused on practical skill-building and hands-on documentation rather than production-ready software delivery.

## Goals

The goal of this path is to build a solid foundation in:

- Security operations and incident response
- Log analysis and threat hunting
- SIEM operations and detection engineering
- Python automation for security workflows
- Structured case-based investigation practice

## Structure of progression

### Phase 0: Foundations
- Networking fundamentals
- Operating systems and security basics
- Log sources and event interpretation
- Core incident response workflows

### Phase 1: SIEM and detection engineering
- Splunk basics, queries, and dashboards
- Detection rule logic and alert tuning
- Log correlation across multiple sources
- Investigation and reporting workflows

### Python for Security
- Python basics applied to security tasks
- Regex, parsing, and file handling
- Threat data extraction and validation
- Practical script development for SOC work

## How this repo is meant to be used

This repo is best used as a portfolio and study archive:

- review the exercises and notes
- follow the progression over time
- use the case studies as examples of analyst thinking
- reference the Python work as proof of applied learning

## Current stage

The projects in this repository reflect the current stage of learning in:

- Splunk/SIEM detection engineering
- threat alerting and signal validation
- Python-based security automation
- full-chain investigation documentation
